# Security Policy

## Supported Versions

The latest released version is the only supported version for security
updates. Older versions are not patched.

## Reporting a Vulnerability

Please report security vulnerabilities to **security@acme.com** rather
than through public GitHub issues.

We commit to:

  - Acknowledging receipt within **48 hours**.
  - Providing an initial assessment within **5 business days**.
  - Coordinating disclosure on a **90-day** standard timeline.

If you'd like to encrypt your report, our PGP key fingerprint is
available upon request.

## Scope

Vulnerabilities in this repository's code, dependencies, and CI
pipeline are in scope. Out-of-scope: third-party services we
integrate with (report directly to that vendor).
